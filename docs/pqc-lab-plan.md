# 双层抗量子实验站实施计划

目标：在本机提供可被现有检测器探测的真实 HTTPS 站点，使用真实随机密钥、ML-DSA-65 私有 CA 与服务器证书、TLS 1.3 X25519MLKEM768 密钥交换。不得预设成功、伪造证书或以 OID/长度代替验签。

项目是 PySide6 桌面应用；主要入口是 `modules/pqc_detect.py:detect`。深度模式验证服务器握手，不发送客户端 Finished；完整 HTTP 事务另用 OpenSSL 客户端验证。

实施顺序：

1. 审查判定、运行现有测试，核实 OpenSSL 实际能力。
2. 增加 `pqc_lab/lab.py`：初始化私有 CA/叶子、隔离 public 与私钥目录、启动 TLS 8443 和本机只读展示页 8080、显式重新验证及停止。OpenSSL 使用现有 3.5+，无系统信任库变更。
3. 用真实证书与服务端做集成测试：证书链严格验证及主机名、真实 Finished/CertificateVerify、完整 HTTPS GET、经典组拒绝、错误主机名和篡改证书拒绝。
4. 修复检测器忽略验签失败/长度错误和跨连接取证的问题，保留 API 契约并增加回归测试。
5. 展示页只读取本次运行生成的证据文件，标记检测时间、入口与信任范围；没有结果则显示未验证。8080 是辅助 HTTP 展示页，8443 才是被测抗量子 HTTPS 入口。
6. 运行集成、回归和独立审查，保存真实报告、详细握手报文及中文搭建说明。

验收：检测器双层通过且服务器握手真实验签成功；OpenSSL 显式信任实验 CA 后完成主机名校验与 HTTP 请求；负向测试确实拒绝。默认仅绑定 127.0.0.1，证书含 localhost/127.0.0.1 SAN，不承诺公网 CA 信任。

初始测试基线：43 passed，1 failed。失败为 `test_wsl_loads_a_font_with_chinese_glyphs`，Windows 当前字体环境无法用 Sans Serif 显示中文；与 TLS 实验无关，最终验证时单独报告。
