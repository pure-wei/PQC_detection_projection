# 真实连接计算复核实施计划

> 实施方式：在当前工作区逐项实现并验证，保留已有未提交修改。

**目标：** 第四页按用户指定的四步，读取前面真实检测或抓包会话，补充同次连接的秘密参数，复核密钥交换、握手签名和加密记录，显示实际输入、过程、输出与缺失项。

**范围：** 复用已有 TLS 1.3 / ML-KEM / ECDH / CertificateVerify / AEAD 实现；不重新生成演示材料。抓包主动复测作为独立连接展示。秘密仅保留内存，公开报告不导出秘密。

协议依据：[RFC 8446 §4.4.3、§4.4.4、§5.2–5.3、§7](https://www.rfc-editor.org/rfc/rfc8446.html)。超出当前实现的 TLS 版本、HRR、0-RTT 等明确报告不支持，不使用替代数据补全。
