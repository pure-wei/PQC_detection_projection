# ML-KEM 计算过程展示

用户范围：ML-KEM-512 / 768 / 1024，以及混合加密中的 ML-KEM。数字签名内部计算不在此次范围内。

目标：展示本次计算实际使用的随机数、参数及相对完整的计算链，所有中间量都对应本次公钥、封装密文和共享秘密。

## 计算与数据

- 新建 `modules/mlkem_trace.py`：按 FIPS 203 最终版实现可跟踪的教学计算，独立于 Qt，无新增依赖。
- 参数：n、q、k、η1、η2、du、dv、环、多项式系数域、NTT 根、密钥/密文/共享秘密长度。
- 随机数：每次由 `os.urandom` 新生成 d、z、m，各 32 字节。保存 SHA3/SHAKE 派生种子、CBD 噪声、矩阵、多项式、编码结果及共享秘密，供本次界面查看。
- 过程：种子扩展、SampleNTT 拒绝采样、PRF/CBD 采样、七层 NTT / 逆 NTT、NTT 域乘法、矩阵向量乘法、ByteEncode/Decode、Compress/Decompress、封装、解封装、重加密比对、篡改后的隐式拒绝。
- 保留完整系数，在各层记录代表性数值代入示例，避免逐条列出所有标量乘加而掩盖主要步骤。
- `pqcrypto` 交叉验证教学实现生成的密文、篡改密文与共享秘密；反向验证库生成的封装。校验不一致即报告失败。
- 混合加密实际使用该计算产生的 ML-KEM 秘密，并展示 HKDF 的输入、盐、PRK、派生密钥及 AES-GCM 参数。

## 界面

- 新建 `modules/mlkem_trace_ui.py`，封装计算树和详情文本视图。
- 独立 KEM、混合加密的结果区域新增“参数与计算过程”页，与原有执行摘要并列。
- 每个节点可查看公式、标准位置、实际输入/输出；多项式包含全部 256 个系数，矩阵逐元素展开。
- 点击运行、输入失败或运算失败时清除旧计算数据，避免混入上一轮随机数。
- 说明计算详情含本轮临时随机数与秘密中间量；只在内存与界面展示，不自动保存或写入日志。原有签名私钥与原始公开数据区保持既有用途。
- 维持后台运算、4096 字节输入限制和等待计算完成后退出的生命周期处理。

## 验证

- 使用带来源与内容摘要的 NIST ACVP 最终版样例，核对三种参数的密钥生成、封装和解封装。
- 独立检验 NTT 逆变换及其乘法与普通环卷积一致，核对压缩边界及位编码。
- 检查全部参数、随机种子、采样、各层变换、密文和共享秘密确实出现在本轮记录中。
- Qt 离屏测试运行两类入口、点击中间量、查看完整数据、清除旧记录与退出。

算法依据：[NIST FIPS 203 (2024/08), §4–8 与算法 5–21](https://nvlpubs.nist.gov/nistpubs/FIPS/NIST.FIPS.203.pdf)。官方样例：[NIST ACVP-Server](https://github.com/usnistgov/ACVP-Server/tree/master/gen-val/json-files)。
